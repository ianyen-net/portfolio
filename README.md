# Ian Yen — Product Designer Portfolio

Static HTML/CSS/JS clone of [ianyen.net](https://www.ianyen.net), including the landing page and all four case study pages.

## Pages Included

- [`index.html`](./index.html) — Home / Portfolio Overview, About & Contact
- [`ai-in-contacts.html`](./ai-in-contacts.html) — Case Study 01: Google Contacts: AI-Powered Contact Intelligence
- [`sharing-design-system.html`](./sharing-design-system.html) — Case Study 02: ShareKit: A Sharing Design System Built for Growth
- [`google-contacts.html`](./google-contacts.html) — Case Study 03: Redesigning Contacts Editor At Scale
- [`sonicare.html`](./sonicare.html) — Case Study 04: Philips Sonicare Connected App Relaunch
- [`style.css`](./style.css) — Unified design system & responsive styles
- [`script.js`](./script.js) — Mobile navigation, scroll reveal animations, and video playback

## Running Locally

Open `index.html` directly in any browser:

```bash
open -a "Google Chrome" index.html
```

Or deploy directly to **GitHub Pages**, **Netlify**, or **Vercel** as a zero-build static site.
